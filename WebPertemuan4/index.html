Apa itu HTML?

HTML adalah bahasa markup untuk membuat struktur halaman web.

Apa itu CSS?

CSS dipakai untuk mengatur tampilan: warna, ukuran, dan tata letak.

Apa itu JavaScript?

JavaScript membuat halaman web menjadi interaktif.

Box Model

Setiap elemen terdiri dari content, padding, border, dan margin.

Flexbox

Flexbox memudahkan penataan elemen secara horizontal dan vertikal.

Grid

CSS Grid dipakai untuk tata letak dua dimensi.

Responsive Design

Tampilan menyesuaikan ukuran layar menggunakan media query.
